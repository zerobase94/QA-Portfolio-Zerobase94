# QA Portfolio Website v3

핵심 포지셔닝을 `문서 분석 기반 Test Case 설계`로 강화한 버전입니다.

## 핵심 메시지
- Requirement / Specification 문서 분석
- 문서의 조건·상태·값·예외사항을 Test Condition으로 변환
- Test Case 설계 및 Review
- Requirement와 기존 TC 비교를 통한 Coverage 보완
- Issue / Spec 변경을 Re-test와 Regression 기준에 재반영

## 사용
`index.html`만 열면 전체 사이트가 동작합니다.
외부 파일 경로에 의존하지 않습니다.
